# Basalt Product Roadmap

| Horizon | Theme | Planned outcomes | Exit evidence |
|---|---|---|---|
| 0.1 — Foundation | Portfolio contracts | Core schema, provider scanners, IaC, Kubernetes, Warehouse, Dashboard, RAG, Agent, and Platform repositories. | Package and infrastructure static quality gates pass. |
| 0.2 — Connected control plane | Real artifact-to-Warehouse flow | Authenticated Warehouse read API, signed scanner artifact admission, index lifecycle, and SLO instrumentation. | End-to-end staged environment with lineage drill-down. |
| 0.3 — Governance | Multi-tenant policy and review | Tenant authorization, retention policy, approval routing, and evidence exports. | Threat model and access-control acceptance tests. |
| 0.4 — Scale | Operational resilience | Recovery exercises, regional strategy, workload autoscaling, and cost visibility. | Recovery-time and capacity evidence from controlled exercises. |

The roadmap is intentionally outcome-oriented. Dates are not fixed until environment ownership, artifact schema versioning, and the Warehouse read API are selected by the product and platform owners.
